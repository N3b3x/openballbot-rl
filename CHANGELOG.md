# Changelog

Notable changes to the repository, newest first. The experiment-level history, with every protocol and number, is the
study log ([docs/research/tracking_study_log.md](docs/research/tracking_study_log.md)). Everything here is simulation only.

## Unreleased

- Front page, documentation index and pipeline walkthrough rewritten around the current GPU pipeline; light and dark
  diagrams and clip previews in `docs/assets/`, generated by `scripts/docs/`.
- `CITATION.cff`, pull request and issue templates, `scripts/docs/check_docs.py` (link and path checker),
  `docs/research/README.md`, repository social preview image.
- Study log entries S118 to S122: goal logic on the true ball centre (g39), design sweep, recommended controller, dead band
  on the ball-centre velocity (g41, retraining).
- ROS 2 package `ballbot_control` with the exported g39 and g34 bundles and parity tests (not run under ROS).

## Earlier

- GPU pipeline on MuJoCo-Warp, design-conditioned LQR plus PPO residual, motion-reference layer, ToF navigation, odometry,
  robot-spec and design-space tools, research website (see the study log).
- December 2025: the upstream environment and training code reorganised into `ballbot_gym/` and `ballbot_rl/` (legacy SB3 path).
- January to May 2025: upstream OpenBallBot-RL by Achkan Salehi (arXiv:2505.18417); the history is preserved in git.
